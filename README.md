# 贾钦基个人简历网页

这是一个不依赖框架的静态网页，可直接部署到 GitHub Pages。

## 发布到 GitHub Pages

1. 在 GitHub 新建一个公开仓库，例如 `resume`。
2. 将本目录中的文件上传到仓库根目录。
3. 打开仓库 `Settings → Pages`，选择 `Deploy from a branch`、`main`、`/ (root)`。
4. 等待部署完成后，网址为：
   `https://jqj.github.io/resume/`
5. 二维码文件见 `qrcode-jqj-resume.png`，内容指向上述网址。
